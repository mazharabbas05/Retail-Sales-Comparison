# Retail Sales Comparison Dashboard (2024 vs 2025)

## Project Overview
This project analyzes and compares retail sales performance
between 2024 and 2025 using Microsoft Power BI.

## Tools Used
- Microsoft Power BI
- DAX
- Excel / CSV

## Business Objectives
- Compare total sales for 2024 and 2025.
- Calculate sales variance.
- Calculate sales variance percentage.
- Analyze sales performance across countries.
- Identify the top 10 countries by sales.

## Key KPIs
- Total Sales 2024
- Total Sales 2025
- Sales Variance
- Sales Variance %

## Dashboard Visuals
- KPI Cards
- Country-wise Sales Comparison Table
- Bar Chart: Total Sales 2025 by Country

## Files Included
- Power BI Dashboard (.pbix)
- Dashboard Export (.pdf)
- dim_stores.csv
- fact_sales_2024.csv
- fact_sales_2025.csv
